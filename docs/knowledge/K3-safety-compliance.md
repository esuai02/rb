# K3 아동 안전·연령등급·개인정보·공정성·수익화

- 출처: 사용자가 2026-10-01 대화에 붙여 넣은 외부 AI 답변("Roblox 교육용 게임에서 함께 설계할 것"). 원문을 정리했다.
- 성격: 참고 자료다. 지켜야 할 규칙은 `intent.md` §5 불변식, 결정은 DEC 표가 정한다.
- 표기: [검증됨 F#] · [미대조] · [자료 주장] (뜻은 K1 머리말과 같다)
- 연결: intent.md INV-4·INV-7·INV-8·INV-9·INV-10·INV-11·INV-12·INV-13, Q3·Q5, DEC-5·DEC-9

자료의 전제: 대상은 **전 세계 9~14세**, 협동 수학 어드벤처. 이 대상 연령은 아직 결정이 아니다 (DEC-9).

## 1. 연령등급과 어린이 노출 (공식 문서 대조함)

| 성숙도 라벨 | 볼 수 있는 이용자 | 상태 |
|---|---|---|
| Minimal · Mild | Roblox Kids(5~8세) · Roblox Select(9~15세) | [검증됨 F4] |
| Moderate | Roblox Select(9~15세) · 일반 Roblox(16세 이상) | [검증됨 F4] |
| Restricted | 연령 확인된 18세 이상만 | [검증됨 F4] |

- 목표 권고: 처음부터 Minimal 또는 Mild [자료 주장 — 위 표와 맞음].
- 출시 전 Creator Hub 의 Maturity & Compliance Questionnaire 를 정확히 쓴다. 답변으로 Roblox 가 맞는 연령대에 게임을 보여 준다 [검증됨 F4]. 제목·썸네일·설명도 연령에 맞아야 한다는 문장은 공식 페이지에서 찾지 못했다 [자료 주장].

**16세 미만(Kids·Select)에게 보이기까지** [검증됨 F5]:
1. 크리에이터 계정: 연령 확인 + 본인 인증(18세 이상은 정부 신분증, 18세 미만은 얼굴 연령 추정) + 2단계 인증
2. 시험 단계: 처음에는 연령 확인된 **16세 이상에게만** 열린다
3. 활발한 이용자 분석(계정 나이·플레이 기록 등) + 실시간 신고·플레이 안전 검토
4. 문턱: 최근 60일 안에 활발한 연령 확인 이용자 **250회 고유 플레이**

→ 구조적 결과 (intent.md Q5·Q6): 목표 연령(9~14세)이 처음부터 들어오지 못한다. 공개 직후 데이터는 16세 이상 이용자 것이다. 16세 미만 학생 파일럿을 어떤 경로로 할지는 확인 안 됨 (DEC-7).

## 2. 설계 표 — 권장과 금지

| 항목 | 권장 | 피할 것 |
|---|---|---|
| 실패 연출 | 밝고 짧은 재도전, 즉시 체크포인트 | 공포·추격·처벌·잔혹한 실패 |
| 경쟁 | 협동 우선, 선택적 기록 경쟁 | 패배자를 조롱·배제하는 구조 |
| 채팅 | 미리 정한 빠른 메시지·이모트·핑 | 외부 연락처, 현실 만남, 자유로운 개인정보 교환 유도 |
| 역할놀이 | 판타지 도시·탐험가·시민 견습생 | 실제 국적·비자·이민·입국 거부·정치 역할놀이 |
| 콘텐츠 | 문화·도시·자연·협동 | 차별, 혐오, 정치 선전, 현실 갈등 소비 |
| 보상 | 탐험·꾸미기·기여·새 행동 해금 | 현금성 보상, 도박형 랜덤 보상, 과도한 결제 압박 |

"입국심사" 대신 쓸 이름: 수학마을 탐험 게이트 · 도시 등록소 · 견습 탐험가 인증 · 시민 퀘스트 관문 · Arrival Gate · Explorer Pass Activation (K2 §3 과 같은 방향).

## 3. 교육 품질 — 수학은 게임 규칙이어야 한다

```text
나쁜 구조: 미션 진행 → 문제창 팝업 → 정답 선택 → 보상
좋은 구조: 수학적 판단 → 월드에서 행동 → 즉시 결과 확인 → 성공/실패 → 재설계
```

예: 일차함수 미션은 정답 숫자를 누르게 하지 않고, 좌표·경사·출발점을 골라 열차 노선을 잇게 한다. 고른 기울기와 절편에 따라 열차가 다른 곳에 도착하면 수학 판단이 곧 게임 행동이 된다.

**따로 검증할 여섯 가지** (Q3 Harness 의 수학 검사 항목):

| ID | 검증 | 질문 |
|---|---|---|
| E1 | 수학적 참/거짓 | 명제와 답이 실제로 맞는가 |
| E2 | 조건 완전성 | 정의역·단위·예외·그림 조건이 빠지지 않았는가 |
| E3 | 교육과정 적합성 | 그 나라·학년의 선수개념과 난도에 맞는가 |
| E4 | 오개념 대응 | 틀린 선택이 흔한 오개념을 진단하는가 |
| E5 | 문해력 부담 | 수학이 아니라 어려운 문장 때문에 실패하지 않는가 |
| E6 | 게임 적합성 | 학습 행동이 플레이 흐름을 끊지 않는가 |

AI 가 문제를 만들면 생성 모델과 검수 모델을 나누고, 반례 탐색·조건 누락 검사·현지 교사 검수를 서로 독립된 관문으로 둔다 (INV-7).

## 4. 개인정보 — 필요한 이벤트만

수집해도 되는 이벤트 (출발점, 정본 목록은 Q2 에서 K5 와 합쳐 정한다): 입장 · 튜토리얼 시작/완료 · 첫 이동 · 첫 미션 시작/성공/실패 · 힌트 사용 · 재도전 · 협동 미션 참가/완주 · 다음 지역 진입 · 세션 종료 · 다음 날 재방문.

수집하지 않을 것 (INV-10): 실명, 학교명, 학년·반, 전화번호, 이메일, 주소 · 실제 만남 장소·시간 · 외부 메신저 ID · 정밀 위치 · 불필요한 자유서술형 학생 답변 · 아동의 음성·얼굴·이미지를 따로 모으는 흐름.

플랫폼 쪽 보호 [미대조]: 13세 미만 계정은 기본적으로 더 제한된 소통 기능을 쓴다. 부모는 자녀 계정의 친구 목록·이용 시간·지출 한도·볼 수 있는 성숙도 범위를 관리한다.

게임 안 "친구와 약속하기"는 이것만 허용한다:

| 안전한 게임 안 약속 | 위험한 약속 |
|---|---|
| 지금 파티 참여 · 공개 매칭 참가 · 게임 안 목적지 핑 · 준비 완료 버튼 · 미리 정한 협동 신호 | "오후 6시에 만나자" · 학교 이름·동네·주소 공유 · 카카오톡·디스코드 연락 · 실제로 어디서 만날지 논의 |

## 5. 멀티플레이 공정성과 서버 권위

무임승차("한 명이 다 하고 나머지는 보상만") 방지 — 보상을 정답 개수나 마지막 버튼 누른 사람에게 몰지 않고 역할별 의미 있는 기여로 준다 (INV-4).

| 역할 | 확인 가능한 기여 |
|---|---|
| 경로 설계자 | 올바른 목적지·경사 후보를 고르고 고침 |
| 실행자 | 실제 이동·운전·조작 |
| 관측자 | 지도·신호·패턴 정보를 확인해 팀에 전달 |
| 지원자 | 자원 전달, 구조, 타이밍 스위치 |
| 팀 전체 | 동시 협동 조건을 채우고 목표 완주 |

역할 배정은 강제가 아니라 선택. 혼자 하는 이용자에게는 NPC 보조·난이도 조정·공개 매칭.

서버 권위 (INV-4, Q3 코드·보안 검사 항목):
- 보상·경험치·자격증·시민권 발급은 서버만 정한다. 클라이언트는 요청만 보낸다
- RemoteEvent 입력을 서버에서 타입·범위·상태별로 검증한다
- 완료 이벤트는 서버 상태로 재시도·중복을 막는다(idempotency)
- DataStore 저장 실패·재접속·중복 수령을 시험한다
- 비정상 반복 호출·순간 이동·보상 중복을 분석 이벤트로 잡는다

## 6. 수익화 윤리 (INV-12, 수익화 여부는 DEC-5)

- 권장: 외형 아이템(의상·탈것 스킨·팀 기지 장식) · 보상 목록과 조건이 분명한 선택적 시즌 패스 · 부모·교사용 유료 관리 도구는 게임 보상과 분리 · 교실·기관 라이선스는 외부 계약 · 핵심 교육 콘텐츠는 무료
- 금지: "틀리면 힌트를 사야 함" · "시민권 시험 재응시는 결제" · 유료 이용자만 학습 진도·해설 접근 · 아동에게 시간 제한 결제 압박 · 가치가 불분명한 확률형 상자 · 친구보다 강해지는 유료 파워 아이템
- Roblox 수익화 기능(유료 접근·게임패스·구독·개발자 상품)은 있다 [미대조].

## 7. UX·성능·접근성 기준 (상세는 K4)

첫 15초 안에 목표가 보임 · 첫 60초 안에 이동·상호작용·첫 성공 · 한 화면 2~3줄 · 크고 떨어진 터치 버튼 · 색만으로 정답·위험·역할 구분 금지 · 자막·효과음 끄기·카메라 민감도·글자 크기 옵션 · 저사양에서 파티클·조명·NPC 수 조절 · 긴 로딩·복잡한 로비·과도한 컷신 제거 · 네트워크 지연·재접속·서버 이동 시험 · 작은 화면에서 문제·대화·보상 UI 겹침 자동 검사. 자료는 "글로벌 Roblox 게임의 절반 이상은 모바일에서 평가받는다고 보고 설계하라"고 권한다 [자료 주장].

## 8. 자동화의 경계 (INV-13)

"지표가 낮으니 AI 가 자동으로 고친다"까지 바로 가면 위험하다.

| AI 가 해도 되는 것 | 사람이 승인할 것 |
|---|---|
| 반복 코드·월드 템플릿·UI 초안 · 문항 후보·NPC 대사·번역 초안 · 수학 조건 누락·반례 후보 탐색 · 코드 리뷰·보안 규칙 검사 · 화면 캡처로 UI 겹침·글자 잘림 탐지 · 로그로 오류·이탈 구간 탐지 · A/B 실험안 초안 | 실제로 재미있는가 · 문화적으로 자연스럽고 존중하는가 · 나라별 교육과정 최종 적합성 · 아동 안전·개인정보·결제 설계 · 라이브 출시·대규모 롤아웃 · 지표를 올리려고 학습 품질을 버리지 않았는가 |

자료가 제안한 층 구성 (intent.md 제품 3층과 같은 방향):
- Intent: 대상 연령·국가·학년·단원, 세션 길이·장르·협동 구조, 학습 목표·오개념·안전 조건
- Graph: 선수개념·단원 그래프, 퀘스트·자격·지역 해금 그래프, 역할·협동·보상 그래프, 번역·용어·현지화 그래프
- Harness: 코드·보안·중복 보상 검사, 수학 명제·반례·난도 검사, UI·모바일·물리·성능 검사, 멀티플레이·재접속·악용 검사, 문화·연령 적합성 검사, 퍼널·유지율·협동·학습 신호 분석

## 9. 출시 전 체크리스트 (intent.md Q5 의 합격 조건 초안)

- [ ] Creator Hub 콘텐츠 성숙도·컴플라이언스 정보를 정확히 썼다
- [ ] 목표 연령대가 플레이할 수 있는 등급인지 확인했다
- [ ] 제목·썸네일·설명도 아동 친화적으로 검수했다
- [ ] 실명·학교·주소·연락처·현실 만남 정보를 요구하지 않는다
- [ ] 현실 입국심사·국적·비자·정치 요소를 가상 탐험 게이트로 바꿨다
- [ ] 수학 정답·조건·반례·학년 적합성을 독립 검증했다
- [ ] 수학이 팝업 퀴즈가 아니라 게임 행동으로 작동한다
- [ ] 친구가 없어도 핵심 진행이 된다
- [ ] 서버가 보상·자격증·시민권을 최종 판정한다
- [ ] 결제 없이 핵심 학습·진행이 된다
- [ ] 작은 모바일 화면과 저사양 기기에서 시험했다
- [ ] 첫 1분·첫 성공·첫 협동·첫 이탈 이벤트를 분석한다
- [ ] 운영 Place 와 스테이징 Place 가 나뉘어 있다
- [ ] AI 자동 변경은 테스트·승인·롤백 절차를 통과한다
- [ ] (공식 문서 대조로 추가) 크리에이터 본인 인증·2단계 인증을 마쳤다 [검증됨 F5]
