# K5 온보딩 — 첫 3~5분에 핵심 재미를 겪고 다시 올 이유를 남긴다

- 출처: 사용자가 2026-10-01 대화에 붙여 넣은 외부 AI 답변("Roblox 온보딩"). 원문을 정리했다.
- 성격: 참고 자료다. 첫 원본 월드는 `intent.md` DEC-1 이 정하고, 게이트 콘셉트는 K2 에 있다. 여기서는 첫 5분의 진행 순서·분기·측정을 다룬다.
- 표기: [미대조] 자료가 Roblox 온보딩 문서를 출처로 달았지만 대조 안 함 · [자료 주장] (뜻은 K1 머리말과 같다)
- 연결: intent.md Q2(분석 이벤트)·Q4(첫 5분 지표)·INV-8·INV-9·INV-13, K2·K4

목표: 사용법을 다 가르치는 것이 아니라 **첫 3~5분 안에 핵심 재미를 직접 겪고 다시 올 이유를 남기는 것.** Roblox 는 FTUE(첫 사용 경험)의 성공을 온보딩 목표 달성률과 D1 재방문율로 보고, 단계별 퍼널과 A/B 로 이탈 구간을 고치라고 권한다 [미대조]. 성공한 온보딩의 공통 원칙: 필수만 가르치기 · 재미에 빨리 닿기 · 더 하고 싶게 끝내기 [미대조].

수학마을 탐험 게이트는 튜토리얼이 아니라 **첫 번째 재미있는 미션**이어야 한다.

## 1. 원칙

- **설명보다 행동 먼저.** "안녕하세요 / 이곳은 Neo Seoul 입니다 / [다음][다음][다음]" 대신 — 도착 3초 뒤 꺼진 게이트, 빛나는 길을 비추는 드론, NPC 한 문장: "신호 하나만 복구하면 수학마을로 갈 수 있어." 걷고·뛰고·만지고·성공한 다음에 세계관을 조금씩 보여 준다.
- **한 번에 하나만.** 이동 → 상호작용(신호 패널) → 판단(드론 위치 선택) → 협동(스위치 두 개 동시) → 보상(게이트 열림 + 탐험 카드). UI 에는 현재 단계만 보이고, 성공하면 다음 행동만 나타난다. 예: "현재 목표: 빛나는 신호 패널에 다가가세요."

## 2. 권장 5분 시나리오

| 시간 | 단계 | 내용 |
|---|---|---|
| 0:00~0:15 | 바로 세계 안으로 | 로비 메뉴 없이 중앙역 게이트 앞에서 시작. 꺼진 거대 게이트·멀리 네온 도시·드론이 비추는 빛의 길·한 문장 목표. HUD: "게이트 신호를 복구하세요." 상점·인벤토리·시민권·랭킹·출석·긴 대화창 없음 |
| 0:15~0:45 | 이동과 카메라 | "빛나는 길을 따라가세요." 모바일 기본 조이스틱 그대로 · PC 는 WASD/화살표 안내 · 게임패드는 스틱 아이콘 · 카메라 안내는 꼭 필요할 때만 짧게 · 10초 안 움직이면 바닥 빛·드론·화살표 강화 |
| 0:45~1:15 | 첫 상호작용 | 긴 설명 대신 근접 프롬프트 하나 `[신호 패널 활성화]`. 누르면 즉시: 패널 점등 → 먼 도시의 전력음 → 드론이 다음 위치를 가리킴 → 진행도 1/3. 목표는 "내가 행동하면 세계가 반응한다"는 감각 |
| 1:15~2:00 | 첫 수학 판단 | 10~20초 안에 이해되고, 틀려도 실패로 보이지 않게. 드론이 좌표 패널 앞에서 멈춤 → 바닥 세 위치 중 드론이 갈 곳 선택 → 맞으면 목표 신호에 도착, 다르면 다른 플랫폼에 착륙 + NPC "세로 위치를 한 칸 더 확인해 보자" + 즉시 다시 선택. 수식·용어·객관식 UI 를 먼저 보이지 않는다. 성공한 뒤 "방금 네가 쓴 건 좌표였어"라고 이름 붙인다 |
| 2:00~3:00 | 첫 협동 | 혼자: NPC 드론이 두 번째 스위치 지원 · 친구: 동시에 켜면 보너스 경로 · 자동 매칭: "함께 게이트를 열 탐험가를 찾는 중" 짧게. 두 사람이 서로 다른 신호 패널 위에 서면 게이트 에너지 2/3 → 3/3. 음성·긴 채팅·역할 설명 강요 없이 월드와 아이콘만으로 이해 |
| 3:00~4:00 | 첫 큰 보상 | 게이트 개방 → 수학마을 전경 → 탐험 카드 발급 → 시민 견습 배지 → 이동 부스터 또는 드론 호출 해금. "+50 코인"이 아니라 "이제 도시의 빠른 이동 레일을 탈 수 있습니다" 같은 새 행동·새 지역 |
| 4:00~5:00 | 다음 목표를 남기고 끝 | "완료" 팝업 대신 빛나는 세 구역(Metro District 열차 노선 복구 · Pattern Palace 빛 패턴 복원 · Han River Dock 수상 드론 구조) 중 선택. 단 **한 곳만 강하게 추천**: "추천: Metro District — 첫 5분 미션 · 친구와 협동 가능 · 이동 부스터 사용 [Metro District 로 가기]" |

참고: 자료의 첫 추천 구역 Metro District(열차 노선 = 기울기·절편)는 원 가이드 예시 "중2 일차함수"와 이어진다 → intent.md §10 후보 C.

## 3. 튜토리얼 UI 패턴

| 상황 | 가장 좋은 UI | 피할 것 |
|---|---|---|
| 이동 | 바닥 빛 경로, 월드 화살표 | 화면 중앙을 가리는 긴 설명 |
| 상호작용 | 근접 프롬프트, 대상 외곽선 | 메뉴에서 버튼 찾게 하기 |
| 수학 판단 | 실제 물체 선택·조정 | 첫 1분부터 객관식 문제창 |
| 협동 | 팀원 방향 핑, 동시 진행 바 | 긴 채팅 지시 |
| 실패 | 월드 결과 + 짧은 힌트 | "오답", "실패", 점수 차감 |
| 보상 | 지역 변화, 기능 해금 | 코인 팝업만 |
| 다음 목표 | 멀리 보이는 랜드마크 + 추천 경로 | 거대한 퀘스트 목록 |

Roblox 가 권하는 기법: 시각 요소 · 맥락형 튜토리얼 · 시간 지연 힌트(일정 시간 진행 없는 플레이어에게만, 지연 시간은 실험으로 조정) [미대조].

## 4. 적응형 튜토리얼 — 행동 기반 분기

| 관찰 | 반응 |
|---|---|
| 5초 안에 이동 | 이동 설명 생략 |
| 15초 동안 안 움직임 | 바닥 길 강화 + "왼쪽 조이스틱으로 이동해 보세요" |
| 첫 신호 선택을 바로 성공 | 다음 수학 힌트 축소 |
| 2회 이상 다른 위치 선택 | 좌표 축을 색·화살표·음성으로 보조 |
| 친구가 같은 서버에 있음 | 2인 동시 스위치 제안 |
| 혼자임 | NPC 드론 지원 |

Harness 는 "튜토리얼을 끝냈는가"만 보지 않고 다음 행동을 관찰해 힌트·난도·동선을 조정해야 한다.

## 5. 측정할 퍼널

최소 이벤트 (출발점 — 정본 목록은 Q2 에서 K3 §4 허용 목록과 합쳐 하나로 정하고, 개인정보 규칙 INV-10 을 지킨다):

```text
session_start → character_spawned → first_input → gate_visible → movement_complete
→ first_interaction → first_math_action → first_math_success → co_play_offered
→ co_play_started → gate_opened → explorer_card_earned → first_zone_entered
→ onboarding_complete → session_end → day_1_return
```

| 이탈 지점 | 의심할 원인 | 먼저 고칠 것 |
|---|---|---|
| session_start → first_input | 로딩, 조작 인지, 카메라 | 스폰 위치·입력 힌트·성능 |
| first_input → first_interaction | 길찾기 실패, 목표 불명확 | 월드 랜드마크·바닥 경로·거리 표시 |
| first_interaction → first_math_action | 설명이 길거나 수학이 갑자기 등장 | 행동형 미션으로 단순화 |
| first_math_action → success | 난도 과함, 피드백 불명확 | 즉시 피드백·힌트·재도전 |
| co_play_offered → started | 협동 진입 마찰 | 친구 초대 단순화·NPC 대체 |
| gate_opened → first_zone_entered | 보상·다음 목표 약함 | 눈에 띄는 지역·즉시 해금 |
| onboarding_complete → D1 return | 장기 목표·복귀 이유 부족 | 다음 자격·팀 프로젝트·이벤트 |

## 6. A/B 테스트 우선순위 — 한 번에 가설 하나

| 실험 | A안 | B안 | 잴 것 |
|---|---|---|---|
| X1 말풍선 vs 바닥 길 | NPC 가 이동 방법을 3문장으로 설명 | NPC 한 문장 + 바닥 빛 경로 + 드론 | 첫 이동까지 시간 · 첫 상호작용 도달률 · 60초 이탈률 · 온보딩 완료율 |
| X2 즉시 힌트 vs 지연 힌트 | 수학 패널이 뜨자마자 힌트 | 10초 또는 첫 실패 뒤에만 힌트 | 첫 수학 행동 시간 · 성공률 · 힌트 사용률 · 재시도율 · 다음 지역 진입률 |
| X3 협동의 위치 | 첫 2분 안에 협동 스위치 | 게이트 통과 뒤 첫 지역에서 협동 | 친구/매칭 참여율 · 온보딩 완료율 · 혼자 온 플레이어 이탈률 · D1 유지율 |

Roblox Experiments·Configs 로 힌트 시간 같은 작은 변수도 A/B 한 뒤 이긴 설정을 실시간 전역 반영할 수 있다 [미대조]. 단 이 저장소에서는 **라이브 설정 반영은 사람 승인 뒤에만** 한다 (intent.md INV-13).

## 7. 하지 말 것

시작 전 30초 넘는 세계관 설명 · 버튼 3개 이상 동시 안내 · 첫 1분 안 상점·결제·시즌패스 노출 · 친구 없으면 진행 불가 · 첫 실패에서 자원 차감 · 긴 NPC 대화와 강제 컷신 · "수학 테스트", "레벨 진단", "오답" 같은 시험 언어 · 설명을 다 읽어야 이동 가능 · 첫 성공 뒤 할 일이 안 보임 · 튜토리얼을 건너뛴 플레이어가 핵심 조작을 다시 배울 방법이 없음.

## 8. 판단 문장

> **플레이어는 5분 안에 "나는 이 세계에서 움직이고, 판단하고, 친구와 함께 도시를 바꿀 수 있다"고 느껴야 한다.**

그러면 게이트가 열리고 탐험 카드가 발급되는 순간은 튜토리얼 완료가 아니라 **첫 번째 도시 복구 성공**으로 기억된다.
