협동 미션형 튜토리얼의 가장 큰 위험은 **협동을 가르치려다 신규 플레이어를 기다리게 하거나, 친구 없는 플레이어를 막아 버리는 것**입니다. 좋은 튜토리얼은 협동을 “필수 관문”이 아니라 **더 빠르고 더 멋진 성공을 만드는 선택적 보너스**로 설계합니다.

Roblox의 온보딩 가이드는 첫 몇 분 안에 핵심 경험·UI·메커닉을 빠르게 이해시키고, 시각적 안내·맥락형 안내·지연 힌트로 진행 마찰을 줄이라고 권장합니다. [create.roblox](https://create.roblox.com/docs/production/game-design/onboarding)

## 가장 중요한 원칙

### 혼자서도 끝나야 한다

첫 튜토리얼에서 절대 만들면 안 되는 구조입니다.

```text
다른 플레이어 1명을 기다리세요.
→ 아무도 오지 않음
→ 게임 첫 2분이 대기
→ 이탈
```

대신 다음 우선순위를 두세요.

```text
친구와 플레이:
빠르고, 협동 연출이 풍부하고, 보너스 보상 존재

혼자 플레이:
NPC 드론 또는 자동 보조장치가 역할을 대체
핵심 진행·학습·첫 보상은 동일하게 달성 가능

자동 매칭:
짧은 시간만 시도하고, 실패하면 즉시 NPC 대체
```

권장 타이머:

| 상태 | 권장 처리 |
|---|---|
| 이미 파티/친구가 같은 서버에 있음 | 협동 버전을 즉시 제안 |
| 혼자 입장 | NPC 보조로 바로 시작 |
| 자동 매칭 선택 | 10~15초만 매칭 시도 |
| 매칭 실패 | 팝업 없이 NPC 드론 투입 |
| 팀원이 중간 이탈 | 즉시 NPC 대체 또는 난이도 축소 |
| 네트워크 지연 | 팀원 상태와 재접속 대기 상태 표시 |

첫 튜토리얼은 혼자 완료해도 열등한 경험처럼 보이면 안 됩니다. “친구와 하면 더 재밌다”는 감정만 남겨야 합니다.

## 협동의 목적을 하나만

협동 튜토리얼에서 동시에 가르치려는 욕심을 내면 실패합니다.

```text
피해야 할 구성:
이동 + 점프 + 카메라 + 채팅 + 역할 선택 +
수학 개념 + 퍼즐 + 타이머 + 전투 + 보상 분배
```

첫 협동 미션에는 아래 하나만 남기세요.

> **서로 다른 두 위치에서 같은 목표를 위해 행동하면 게이트가 열린다.**

예시입니다.

```text
플레이어 A:
빛나는 좌표 타일 위에 선다.

플레이어 B 또는 NPC 드론:
반대편 신호 패널을 활성화한다.

팀:
두 신호가 동시에 켜지면 게이트가 열린다.
```

여기서 학습 행동을 넣고 싶다면 한 역할만 수학적 판단을 하게 하고, 다른 역할은 실행·관찰·타이밍을 담당하게 하세요. 모두에게 문제를 풀게 하면 협동이 아니라 동시에 보는 시험이 됩니다.

## 역할은 비대칭이되 동등하게

좋은 협동은 각자 다른 일을 하지만, 누구도 “정답만 맞히는 주인공”이나 “버튼만 누르는 조수”가 되지 않는 것입니다.

| 역할 | 실제 행동 | 수학/사고 기여 | 보상 가치 |
|---|---|---|---|
| 경로 탐색자 | 지도에서 신호 위치를 찾음 | 좌표·방향·비교 | 같은 비중 |
| 실행자 | 드론·열차·에너지 장치 조작 | 결과 관찰·조정 | 같은 비중 |
| 동기화 담당 | 타이밍 신호를 맞춤 | 순서·패턴·조건 판단 | 같은 비중 |
| 지원자 | 부품 전달·위험 구간 보호 | 자원·거리·우선순위 | 같은 비중 |

초기에는 2인 역할만 쓰는 편이 낫습니다. 3~4인 역할 협동은 정식 미션에서 확장하세요.

또한 역할을 고정하지 마세요. 한 번은 A가 지도, 다음에는 A가 실행을 맡게 해야 특정 플레이어가 계속 “쉬운 역할”만 하거나, 잘하는 친구가 모든 판단을 독점하는 상황을 줄일 수 있습니다.

## 대기와 동기화 마찰

협동 미션은 재미보다 기다림이 먼저 느껴지기 쉽습니다. 특히 모바일 사용자는 지연·카메라·조작 문제까지 겹칩니다.

### 줄여야 할 것

- 모두 준비 버튼을 누를 때까지 무기한 대기
- 한 명이 실패하면 팀 전체가 처음부터 재시작
- 팀원 중 한 명이 로딩 중이면 미션 전체 정지
- 정확히 같은 프레임에 눌러야 하는 버튼
- 긴 역할 설명을 팀원 모두가 읽어야 진행되는 구조
- 한 명이 컷신을 보는 동안 다른 사람은 조작 불가
- 음성·자유 채팅이 없으면 해결할 수 없는 퍼즐

### 넣어야 할 것

- 준비 상태를 색·아이콘·이름으로 명확히 표시
- 동시 행동에는 2~4초의 허용 창 제공
- 팀원이 멀어지면 월드 안에 방향 빔 표시
- 역할을 바꾸거나 다시 시도하는 버튼
- 한 명이 이탈하면 자동 대체
- 10초 내 핵심 행동에 도달하도록 짧은 동선
- 실패 후 체크포인트에서 즉시 재시도
- 팀 전체가 성공할 때 모두에게 동시 보상

“동시 버튼”도 실제 동시성보다 **서로 맞췄다고 느끼게 하는 경험**이 중요합니다. 서버 판정 허용 창을 둬야 네트워크 지연으로 억울하게 실패하지 않습니다.

## 설명은 공유하지 말고 분산하기

협동 튜토리얼에서 흔히 하는 실수는 팀원 전원에게 같은 긴 설명을 띄우는 것입니다.

```text
팀 전체 공통 설명:
“당신은 좌표평면의 x축과 y축을 이해해야 하며…”
```

대신 각자에게 필요한 정보만 짧게 줍니다.

```text
경로 탐색자:
“지도에서 빛나는 위치를 찾으세요.”

실행자:
“드론을 파란 신호까지 운반하세요.”

팀 전체:
“두 신호가 연결되면 게이트가 열립니다.”
```

이 방식은 긴 텍스트를 줄이고, 각 플레이어가 자신이 필요한 행동을 즉시 이해하게 합니다. 언어가 달라도 아이콘·색·방향선·월드 내 표식이 의미를 전달하도록 설계하면 글로벌 현지화에도 유리합니다.

## 실패는 팀 탓이 아니다

협동 미션에서 실패가 “누구 때문에 망했다”로 보이면 신규 플레이어는 친구와 하기 싫어집니다. 특히 아이들 게임에서는 조롱·배제의 원인이 될 수 있습니다.

### 나쁜 피드백

```text
실패: Alex가 스위치를 누르지 않았습니다.
팀원이 미션을 망쳤습니다.
```

### 좋은 피드백

```text
신호가 잠깐 어긋났어요.
두 불빛이 동시에 켜지면 게이트가 열립니다.
[바로 다시 시도]
```

피드백은 개인 비난이 아니라 **공동 상태와 다음 행동**을 보여 줘야 합니다.

```text
좋은 협동 피드백:
- “신호 1/2 연결됨”
- “팀원이 준비 중”
- “2초 안에 함께 활성화하세요”
- “다음에는 드론이 먼저 도착하면 더 쉬워요”
```

## 보상은 팀 전체에 공정하게

첫 협동 미션에서는 기여도 계산을 복잡하게 하지 마세요. 정답을 선택한 사람이나 마지막 버튼을 누른 사람만 보상을 받으면, 다른 플레이어는 곧 무임승차자가 되거나 역할을 두고 싸우게 됩니다.

권장 보상 구조입니다.

```text
기본 보상:
완주한 모든 팀원에게 동일 지급

협동 보너스:
- 팀원 구조
- 역할 교대
- 첫 시도 성공
- 제한 시간 내 함께 완료
- 다른 플레이어 도움 요청에 응답

개인 성장:
각 역할의 실제 참여 기록은 별도로 남기되,
첫 튜토리얼 보상에서 차등을 크게 두지 않음
```

서버가 보상·자격증·시민권 점수를 최종 판정하고, 클라이언트는 행동 요청만 보내도록 해야 합니다. 그렇지 않으면 RemoteEvent 조작으로 자격증·보상 중복 수령 문제가 생길 수 있습니다.

## 채팅 없이도 작동하게

글로벌 아동 대상 게임에서 협동을 자유 텍스트 채팅이나 음성에 의존하면 안 됩니다. 언어 장벽, 연령 안전, 신고·괴롭힘 위험이 모두 커집니다.

첫 협동 튜토리얼에는 아래 정도면 충분합니다.

```text
[여기로 오기]
[준비 완료]
[도움 필요]
[따라와]
[좋았어!]
[다시 해보자]
```

추가로 월드 UI를 활용하세요.

- 목적지 핑
- 역할 아이콘
- 준비 체크 표시
- 팀원까지의 거리
- 신호 연결선
- 카운트다운
- 도움 요청 빔
- 팀 전체 진행 바

이것은 번역 부담도 낮고, 어린 플레이어의 안전에도 유리합니다.

## 수학을 협동에 연결하는 법

수학을 “한 명이 풀고 모두가 통과하는 퀴즈”로 만들지 마세요. 대신 정보와 행동을 나눕니다.

### 예: 좌표 게이트

```text
탐색자:
지도에서 목표 신호의 위치를 본다.
예: (3, -2)

실행자:
월드의 드론을 실제로 이동시킨다.

동기화 담당:
도착 시점에 신호 증폭기를 작동한다.

팀 결과:
드론이 정확한 위치에 도착하면 게이트 에너지가 충전된다.
```

단, 초반에는 숫자 표기만으로 막히지 않도록 바닥 타일·방향 화살표·색 구역으로 보조합니다. 수학은 플레이를 방해하는 암호가 아니라, 더 좋은 경로를 찾게 하는 도구여야 합니다.

## 측정해야 할 지표

협동 튜토리얼은 “완료율” 하나만 보면 안 됩니다. 다음을 분리해서 측정하세요.

| 지표 | 의미 | 위험 신호 |
|---|---|---|
| 협동 제안 노출률 | 신규 이용자가 협동 기회를 봤는가 | 안내 자체가 안 보임 |
| 협동 시작률 | 친구/매칭/NPC 경로 중 무엇을 선택했는가 | 진입 과정이 복잡함 |
| 매칭 대기 시간 | 실제 팀을 얼마나 기다렸는가 | 10~15초를 넘으면 이탈 위험 |
| NPC 대체율 | 혼자 온 플레이어 비율 또는 매칭 실패율 | 매칭 품질/유입 규모 문제 |
| 협동 완주율 | 미션의 이해·난도·동기화 품질 | 역할/설명/조작 문제 |
| 중도 이탈률 | 팀원이 나가거나 플레이어가 나간 비율 | 대기·비난·복잡성 문제 |
| 재시도율 | 실패 뒤 다시 해보는 비율 | 너무 낮으면 좌절, 너무 높으면 난도 과함 |
| 팀원별 기여 분포 | 한 명 독점/무임승차 여부 | 역할 설계 불균형 |
| 첫 지역 진입률 | 튜토리얼 뒤 실제 게임으로 이어지는가 | 보상·다음 목표 약함 |
| 협동 후 D1 유지율 | 협동 경험이 복귀로 이어졌는가 | 강제 협동이 피로했을 가능성 |

Roblox 온보딩 가이드는 온보딩 단계별 완료율과 FTUE를 통과한 사용자의 D1 유지율을 핵심으로 보고, 시각적 안내·맥락형 설명·진행이 막혔을 때의 지연 힌트를 활용하라고 설명합니다. [create.roblox](https://create.roblox.com/docs/production/game-design/onboarding)

## 자동 검수 Harness

협동 튜토리얼은 사람이 매번 2~4계정을 조작하지 않아도 상당 부분 자동 테스트할 수 있습니다.

```text
테스트 1:
플레이어 1명 → NPC 보조 → 3분 내 게이트 통과

테스트 2:
플레이어 2명 → 서로 다른 역할 → 허용 시간창 내 동시 신호 성공

테스트 3:
플레이어 2명 중 1명 이탈 → NPC 대체 → 미션 지속

테스트 4:
한 명이 지연/재접속 → 진행 상태 복구 및 보상 중복 없음

테스트 5:
양쪽이 동시에 완료 요청 → 팀원 모두 보상 1회씩

테스트 6:
한 플레이어가 아무 행동도 안 함 → 다른 플레이어가 막히지 않고 진행

테스트 7:
모바일·PC 혼합 → 두 입력 방식 모두 핵심 행동 가능
```

Roblox Studio의 자동화 테스트 기능을 활용하면 테스트 세션을 프로그래밍 방식으로 실행하고, 게임 내 서버 스크립트에서 결과를 종료·보고하도록 구성할 수 있습니다. [create.roblox](https://create.roblox.com/docs/reference/engine/classes/StudioTestService)

## 출시 전 체크리스트

- [ ] 친구가 없어도 첫 협동 미션을 3~5분 안에 끝낼 수 있다
- [ ] 자동 매칭이 10~15초 이상 플레이어를 붙잡지 않는다
- [ ] 팀원 이탈·재접속 때 NPC 대체 또는 난이도 조정이 작동한다
- [ ] 각 플레이어가 서로 다른 의미 있는 행동을 한다
- [ ] 단순 버튼 누르기 역할만 계속 맡는 사람이 없다
- [ ] 역할 안내가 한 문장·아이콘·월드 표식으로 이해된다
- [ ] 자유 텍스트나 음성 채팅 없이도 협동이 가능하다
- [ ] 동시 행동에 네트워크 지연을 고려한 허용 창이 있다
- [ ] 실패가 특정 팀원을 비난하지 않는다
- [ ] 모든 참여자가 공정한 기본 보상을 받는다
- [ ] 보상·자격·시민권은 서버에서만 판정된다
- [ ] 혼자/친구/자동 매칭/이탈/재접속/모바일 환경을 테스트했다
- [ ] 협동 완료 뒤 다음 지역과 다음 목표가 즉시 보인다

## 결론

협동 미션형 튜토리얼은 “친구와 해야만 통과하는 시험”이 아니라, 다음을 체감시키는 첫 3분이어야 합니다.

> **혼자서도 도시를 움직일 수 있고, 친구와 함께하면 더 크고 빠르게 도시를 바꿀 수 있다.**

이 원칙만 지키면 수학마을 탐험 게이트는 조작 교육, 수학적 사고, 안전한 협동, 시민권 수집 루프를 한 번에 여는 매우 강한 온보딩이 될 수 있습니다.
