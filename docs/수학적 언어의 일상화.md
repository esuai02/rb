Roblox “입국심사” 게임의 초기 온보딩은 현실 이민 심사가 아니라, \*\*가상 도시의 탐험 등록·신호 언어 게이트\*\*로 바꾸는 것이 가장 안전하고 재미있습니다. 첫 3\~5분의 목표는 플레이어를 평가하는 것이 아니라 “도시는 네가 말한 위치·방향·변화를 알아듣는다”는 첫 성공을 주는 것입니다.



Roblox는 FTUE에서 첫 몇 분 동안 플레이어가 핵심 루프·진행·단기/중기/장기 목표를 이해하고 재미를 느끼는지를 중요하게 보며, 막힌 플레이어에게만 시간 지연 힌트를 주는 방식을 권장합니다. \[devforum.roblox](https://devforum.roblox.com/t/learn-more-about-first-time-user-experience-onboarding/2621940)



\## 콘셉트 전환



\### 피해야 할 입국심사



```text

여권 검사

→ 국적 선택

→ 비자 심사

→ 문제 정답 여부로 통과/거부

→ 실패하면 입장 불가

```



이 방식은 현실 이민·국적·배제·시험을 연상시키고, 글로벌 아동 대상 게임에서 불필요한 민감성을 만듭니다.



\### 권장: 도시 언어 등록 게이트



```text

Neo Seoul Central 도착

→ 도시 신호가 꺼져 있음

→ 탐험 카드 활성화 필요

→ 위치·방향·변화의 도시 언어를 사용

→ 게이트와 연결

→ 탐험가 등록 완료

→ 첫 지역 진입

```



권장 명칭은 다음입니다.



| 현실 심사 표현 | 게임 내 표현 |

|---|---|

| 입국심사대 | 도시 언어 게이트 |

| 심사관 | 신호 안내자 루미 |

| 여권 | 탐험 지도책 |

| 비자 | 탐험 허가 배지 |

| 입국 거부 | 신호 재조정 |

| 시민권 | Neo Seoul 탐험가 배지 또는 명예 시민 타이틀 |



Roblox의 Kids/Select 대상 게임은 연령 적합성·안전성 평가를 거치며, 민감한 이슈를 중심 주제로 한 Experience는 13세 미만에게 기본적으로 제한될 수 있습니다. 따라서 현실 정치·국경·이민·국가 신분 요소에서 거리를 두는 편이 유리합니다. \[github](https://github.com/Roblox/creator-docs/blob/main/content/en-us/production/publishing/kids-and-select.md)



\## 온보딩 목표



초기 온보딩에서 가르칠 것은 딱 네 가지입니다.



```text

1\. 이 세계에서 나는 탐험가다.

2\. 빛나는 목표를 따라 움직인다.

3\. 도시 언어를 쓰면 도시가 반응한다.

4\. 친구와 하면 더 멋진 길이 열린다.

```



가르치지 말아야 할 것:



```text

\- 모든 수학 용어 정의

\- 도시 전체 세계관

\- 인벤토리·상점·시즌패스

\- 시민권 전체 조건

\- 자격증 10개 목록

\- 복잡한 멀티플레이 규칙

\- 긴 NPC 대화

```



\## 첫 5분 설계



\### 0:00\~0:12 — 도착: “여기가 어디지?”



플레이어는 Neo Seoul Central의 거대한 게이트 앞에서 스폰됩니다. 게이트 너머에는 미래 도시·열차·빛나는 궁전 실루엣이 보이고, 게이트는 꺼져 있습니다.



```text

루미:

“탐험가! 도시 신호가 멈췄어.

세 가지 말만 다시 연결하면 길이 열려.”

```



화면에는 한 줄만 유지합니다.



```text

목표: 게이트 신호를 복구하세요. 0/3

```



\#### 화면 규칙



\- 강제 컷신은 2초 이내

\- 상점·인벤토리·랭킹·결제 UI는 숨김

\- 게이트, 바닥 빛 길, 첫 신호 패널만 강하게 보임

\- 플레이어 입력은 즉시 허용

\- 5초 동안 입력이 없을 때만 이동 힌트 표시



```text

“빛나는 길을 따라가 보세요.”

```



\### 0:12\~0:40 — 첫 움직임: “나는 움직일 수 있다”



빛나는 바닥 경로와 드론이 첫 신호 패널까지 안내합니다.



```text

거리 20 studs:

\- 패널 외곽 청록색 하이라이트

\- 드론이 그 방향으로 이동



거리 10 studs:

\- \[신호 켜기] ProximityPrompt 표시



거리 5 studs:

\- 패널 자체가 약하게 진동·점등

```



첫 상호작용은 즉시 성공해야 합니다. 홀드, 수학 판단, 협동 대기, 복잡한 UI를 넣지 마세요.



```text

\[신호 켜기]

→ 패널 점등

→ 게이트 링 1/3 회전

→ “도시는 네 행동을 들었어.”

```



`ProximityPrompt`는 Attachment, BasePart, Model에 연결할 수 있으며, 플레이어가 지정된 거리 안으로 들어오면 기기별 입력 힌트를 제공하는 방식이라 첫 상호작용에 적합합니다. \[create.roblox](https://create.roblox.com/docs/tutorials/use-case-tutorials/ui/proximity-prompts)



\### 0:40\~1:40 — 위치 신호: “두 번 말하면 위치가 된다”



두 번째 신호는 좌표를 시험 보지 않고, 위치를 전달하는 게임으로 만듭니다.



```text

루미:

“드론은 위치를 두 번 들어야 길을 알아.

옆으로 어디까지? 그리고 위아래로 어디까지?”

```



플레이어는 바닥의 세 개 플랫폼 중 하나로 이동합니다.



```text

A: 오른쪽 2, 위 1

B: 오른쪽 2, 아래 1

C: 왼쪽 2, 위 1

```



플랫폼 위에 수식이나 답 번호를 크게 쓰지 마세요. 색·높이·방향 화살표·거리 빛으로 표현합니다.



\#### 결과 피드백



```text

정확한 위치:

드론이 신호에 도착

→ 게이트 링 2/3

→ “두 위치를 차례대로 알려 줬어.”

→ “도시는 이런 위치 말을 ‘좌표’라고 불러.”



가까운 위치:

드론이 옆 플랫폼에 착륙

→ “가로 방향은 맞아. 위아래를 한 번 더 보자.”

→ 즉시 다시 이동 가능



다른 위치:

드론이 다른 빛을 비춤

→ “드론이 다른 신호를 찾았어. 빛나는 방향을 따라가 보자.”

→ 바닥 방향선 강화

```



절대 “오답”, “불합격”, “입국 거부”를 쓰지 마세요.



\### 1:40\~2:40 — 변화 신호: “길의 말”



세 번째 신호에서 “기울기”를 먼저 설명하지 않습니다.



```text

상황:

열차 빛길이 목표 플랫폼보다 낮게 연결돼 있음.



루미:

“빛길을 조금 더 올라가게 할 수 있을까?”

```



플레이어는 세 가지 레버 또는 경사 부품을 선택합니다.



```text

\[더 올라가게]

\[그대로]

\[더 내려가게]

```



선택하면 실제 열차 또는 빛 구슬이 움직입니다.



```text

성공:

목표 플랫폼에 도착

→ “길의 올라가고 내려가는 정도를

도시에서는 ‘기울기’라고 불러.”



낮게 도착:

“목표보다 낮게 도착했어.

조금 더 올라가게 바꿔 볼까?”

```



이 단계에서 중요한 것은 플레이어가 “기울기 = 숫자 공식”보다 \*\*더 가파르게/덜 가파르게라는 일상어와 연결된 도시 언어\*\*로 느끼는 것입니다.



\### 2:40\~3:30 — 협동 맛보기: “함께 말하면 연결된다”



협동은 신규 플레이어를 막으면 안 됩니다.



```text

친구가 같은 서버에 있음:

\- 좌측/우측 신호 스위치 제안

\- 각각 0.5초 홀드

\- 3초 안에 양쪽 준비 시 게이트 개방



혼자:

\- 라인 드론이 반대쪽 스위치로 자동 이동

\- 동일한 핵심 진행·보상



매칭 선택:

\- 최대 10초만 시도

\- 실패 시 자동 NPC 대체

```



UI는 짧아야 합니다.



```text

나: 준비됨

팀원/드론: 신호 연결 중

```



협동 실패 문구:



```text

“두 신호가 잠깐 어긋났어.

같은 시간에 빛나면 연결돼.”

```



누구의 잘못인지 표시하지 않습니다.



\### 3:30\~4:15 — 게이트 개방: “나는 통과한 게 아니라 연결했다”



게이트가 열리는 장면은 가장 큰 보상입니다.



```text

신호 3/3

→ 세 개의 게이트 링 점등

→ 도시 빛줄기 합류

→ 단청풍 패턴이 나타남

→ 포털 개방

→ Metro District·Pattern Palace·Han River가 멀리 보임

```



보상 카드는 “합격”이 아니라 아래처럼 표시합니다.



```text

도시 언어 탐험 카드 활성화



발견한 말:

\[좌표] 위치를 정확히 알려 주는 도시 말

\[기울기] 길의 변화를 설명하는 도시 말



새 기능:

Metro District로 이동

```



\### 4:15\~5:00 — 다음 목표: “다음에는 어떤 도시 말을 쓸까?”



처음에는 선택지를 너무 많이 주지 마세요.



```text

추천 탐험:

Metro District



목표:

멈춘 열차 노선을 복구하세요.



새 도시 말:

더 가파르게 / 더 완만하게 / 같은 높이



보상:

Metro Pathfinder 탐험 스탬프



\[Metro District로 가기]

```



나머지 지역은 실루엣이나 “곧 열림” 정도로만 보여 줍니다.



\## ProximityPrompt 배치



초기 온보딩에는 Prompt를 최대 3개만 순차적으로 활성화하세요.



| 단계 | 대상 | ActionText | ObjectText | 홀드 |

|---|---|---|---|---|

| 1 | 첫 신호 패널 | `신호 켜기` | `게이트 신호` | 없음 |

| 2 | 변화 레버 | `길 조절` | `빛길 콘솔` | 없음 |

| 3 | 협동 스위치 | `신호 준비` | `프리즘 스위치` | 0.4\~0.8초 |

| 4 | 포털 | `Metro로 이동` | `탐험 게이트` | 0.3\~0.5초 |



Prompt는 플레이어가 실제로 상호작용 거리 안에 들어왔을 때 표시되며, `ActionText`, `ObjectText`, 키보드/게임패드 입력, `HoldDuration`, 표시 거리를 설정할 수 있습니다. \[create.roblox](https://create.roblox.com/docs/tutorials/use-case-tutorials/ui/proximity-prompts)



\## 지연 힌트 설계



모든 사람에게 튜토리얼 말풍선을 띄우면 숙련자는 지루해집니다. 행동이 멈춘 경우에만 힌트를 강화하세요.



| 플레이어 상태 | 시스템 반응 |

|---|---|

| 5초간 입력 없음 | “빛나는 길을 따라가 보세요.” |

| 10초간 반대 방향 이동 | 드론이 되돌아와 바닥 경로 재점등 |

| 15초간 첫 Prompt 미사용 | 대상 Highlight 강화 + 거리 표시 |

| 위치 신호 첫 실패 | 방향·높이 단서 하나만 추가 |

| 같은 유형 두 번째 실패 | 정답 플랫폼 쪽 바닥 패턴 점멸 |

| 협동 대기 10초 | NPC 드론 자동 대체 |

| 게이트 개방 후 10초 정지 | Metro 포털을 향한 짧은 빛길 표시 |



Roblox는 진행이 막힌 플레이어에게만 표시되는 timed hint가, 숙련 플레이어의 온보딩 시간을 늘리지 않으면서 도움을 주는 방식이라고 설명합니다. \[devforum.roblox](https://devforum.roblox.com/t/learn-more-about-first-time-user-experience-onboarding/2621940)



\## 입국심사 감각을 살리는 연출



“심사”라는 드라마는 살리되 현실 행정·국적·이민의 느낌은 빼야 합니다.



\### 사용할 수 있는 연출



```text

\- 탐험 카드가 빛을 받아 활성화됨

\- 게이트가 플레이어의 신호 패턴을 읽음

\- 드론이 ‘도시 언어’를 번역함

\- 세 개의 신호가 맞으면 포털이 열림

\- 지도책에 첫 스탬프가 찍힘

\- 안내 NPC가 “도시가 널 알아들었어”라고 말함

```



\### 피해야 할 연출



```text

\- 실제 여권·비자·입국 도장

\- 국가·국적·언어·인종 선택이나 평가

\- 심사관이 플레이어를 거부하거나 심문

\- 실패 시 대기실·추방·벌점

\- 현실 국기·정부기관·국경 통제 UI

\- “합격자/불합격자” 랭킹

```

| 완료 → D1 재방문 | 장기 목표 부족 | 첫 자격·도시 의뢰·공동 프로젝트 제시 |



\## 초기 MVP 범위



처음부터 좌표·기울기·비율·협동·시민권을 모두 넣지 마세요.



```text

MVP 0.1:
```
